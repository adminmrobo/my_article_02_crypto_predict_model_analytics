1

400韩元误差的陷阱：RMSE与MAE的局限，以及偏离率（Accuracy Ratio）

指标的再发现 偏差(Bias)检测
传统回归指标（RMSE、MAE）的盲点

RMSE = √( 1/nT ∑ ( ŷt − yt )² )
当误差为 $400（或400韩元） 时，比特币在$2,000时的400误差（误差率20%）和$60,000时的400误差（误差率0.67%）被一视同仁地评价。也就是说，由于 价格量级依赖性 ，无法客观判断模型在哪一段时期真正优秀。而且取平方或绝对值后，也看不出模型是一直报价偏高（高估）还是偏低（低估）。

本论文的替代方案：偏离率（Accuracy Ratio）

Accuracy Ratio = ( ŷt / yt ) − 1
1. 量级不变性： 与价格大小无关，误差被换算成纯百分比，从而可以客观地跨时期比较。
2. 方向性偏差检测： 大于0即为高估（Overestimation），小于0即为低估（Underestimation），立刻可以区分。

指标对比小结：论文为何关注偏离率的"均值与标准差"？

只看误差均值，正误差与负误差相互抵消，会出现看似为0的扭曲。本研究计算了112天的偏离率分布，同时分离出 均值（偏差方向）与标准差（预测的波动稳定性）。

• RNN: 均值 -5.5%（低估），标准差 2个百分点（最稳定区间）
• LSTM: 均值 +6.7%（高估），标准差 4个百分点（稳定跟随）
• ARIMA: 均值 -7.6%（严重低估），标准差 11个百分点（预测大幅跳动）
果蝇研究员

等等，误差正好400韩元的话，不是预测得挺准吗？教科书也都让大家先看RMSE和MAE啊！

Money-Robo

啧啧，果蝇研究员真没有账本感！1,000韩元的杂币错400就是40%的惨案；6,000万韩元的比特币错400，误差率0.0006%，堪称神准。只看绝对误差数字，是没法给投资估价的，哔咻！

助手

没错。而且RMSE做了平方，会掩盖模型是一直报价偏高还是偏低这个"方向(Bias)"。所以论文用 Accuracy Ratio = (预测价 / 实际价) − 1 抹去量级，再把均值和标准差分开来评价。

博士

说得好。只有使用去掉单位的比率指标，才能在同一个层面上严格比较2019年的比特币和2023年的比特币！

模型内部结构对比：RNN、LSTM与HMM

结构图(Diagram) Markov vs HMM

用可视化示意图分解数据沿时间轴流动时每个模型的内部计算机制。

示意图A：循环神经网络结构对比（简单循环 vs 三重门控）

传统马尔可夫链（Markov Chain）

"看见的就是状态"： 假设系统的所有状态(State)都完全暴露在外、可以直接观测。
• 例如："今天收盘价上涨了"这个观测值本身就成为状态 S1，而且只计算 P(St | St-1 的转移概率。但这无法反映复杂而看不见的市场情绪。

隐马尔可夫模型（HMM, Hidden Markov Model）

"观测值背后藏着看不见的局面"： 真实的市场状态 qt（牛市、熊市、横盘、波动率爆发等）是隐藏的、看不见的。
• 我们只能看到价格变化率 yt，仅此而已。也就是说，模型由 状态转移概率（A）与隐状态下观测值蹦出来的发射概率（B, Emission）的双重概率结构。

示意图B：隐马尔可夫（HMM）的双层结构

果蝇研究员

神经网络搞得那么复杂干嘛。RNN不就是把上一次的输出再塞回去吗？那为什么非得搬来带遗忘门、细胞状态这些复杂玩意的LSTM？

助手

基础RNN才过10~20天梯度就消失了(Gradient Vanishing)，会把一个月前的冲击忘得一干二净。而LSTM通过上方的 Cell State (C_t)（细胞状态）高速公路，能把重要的金融记忆完好地传到60天后。

Money-Robo

而且HMM是另一个层次的！普通马尔可夫只盯着眼前的数字，"昨天涨了所以今天涨"；HMM却能靠双重概率，看穿幕后隐藏的"机构吸筹局面"或"恐慌抛售局面"这类隐状态(Hidden State)！

博士

完全正确。把我们观测到的价格（发射）背后真实存在的市场状态(Regime)分离出来——这正是隐马尔可夫模型的数学精髓。

3

HMM的核心价值：最优状态路径（Optimal Path Decoding）解读

Viterbi Decoding 9个最优状态

论文实证：HMM为什么追踪"路径(Path)"而不是精确价格？

在论文第10页[图4-10]中，作者把使RMSE最小的最优隐状态个数定为 9个（Number of states = 9）。 HMM并不适合去命中42,500美元这样的精确价格点。它改用维特比(Viterbi)算法提取 "当前比特币市场正经过9个局面中的哪几个、正走向何方？"——最优状态转移路径，这才是关键：

Path* = argmaxQ P( Q | Y ) = argmax(q1, ..., qT) P( q1, q2, ..., qT | y1, y2, ..., yT )

也就是说，给定观测到的价格序列(Y），找出市场最可能经历的潜在局面序列(Q*）——这就是反向追踪(Backtracking)技术。

交互式隐状态转移矩阵（Transition Matrix）与最优路径

基于论文[图4-11]的转移概率矩阵复现的9个隐状态间的转移路径。点击按钮，解码状态之间的最优转移轨迹。

等待中：点击按钮即可追踪路径。
果蝇研究员

咦？HMM的预测偏离率是+12.3%，点价格误差比神经网络大得多！那这模型不是没用吗？

助手

不是的，果蝇研究员！HMM的主要目的不是猜明天收盘价是4,250万还是4,280万韩元。它是靠 Path* = argmax P(Q|Y) 来探测市场正处在"低波动横盘（状态1）"，还是正在向"急速上涨动能（状态5·6）"转移的局面探测器。

Money-Robo

没错！看转移矩阵的对角线，状态5和状态6的自保持概率高达70~90%！牛市一旦启动，那条局面路径就会带上强大的惯性——维特比算法证明了这一点！

博士

结论是：价格的精细点预测交给LSTM，宏观市场局面的转换路径把握与HMM并用——这才是明智的量化策略！
